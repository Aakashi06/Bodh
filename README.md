Bodh is a **multilingual voice AI learning companion** that lets users ask questions naturally and learn through voice conversations.

It supports **English, Hindi, Hinglish, and other supported Indian languages**, with speech-to-text, AI reasoning, and natural voice responses powered by the **Sarvam API**.
